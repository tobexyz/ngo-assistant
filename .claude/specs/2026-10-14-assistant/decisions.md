## 2026-10-15 — Design changes from research task 1.1 (docs/tech.md sections 11-18)
- `tools` and `format` are never sent in the same request (the 1B model put schema keys into a tool call): the forced final call has no tools, as designed.
- Citations: exact tenant ids kept; strings containing exactly one known id mapped and counted as `repaired_citations`; others dropped and counted as `invalid_citations`. `abstain` is recorded as the model sets it.
- Retrieved-text budget lowered from 6000 to 3000 tokens (cold prefill about 22 tokens/s on this CPU; 268 s for about 6000 tokens, one observation). Warm-up call added; CLI default `NGO_LLM_TIMEOUT_S=900` when unset.
- Model digest comes from `client.list().models[].digest` (not `show()`).
- Variant A search uses Postgres 'simple' full-text search: no stemming (German inflection misses, for example Rechenzentren vs Rechenzentrum). Known limitation of A: reported, not fixed in this spec.
- Open, needs the user's approval: the research task created a scratch schema `scratch_research` (tables c, d2000, d2001, docs) in the live database and was not allowed to remove it (the destructive-SQL guard requires the user's explicit approval). It does not interfere with the `public` schema where ingest will write.
